# M2/M3 实现状态

## 状态

M2 和 M3 的核心纵向切片已完成，并在一份真实管理员 CPU trace 上验证：

```powershell
wperf record -F 999 -o cpu.etl -- wperf_cpu_burn.exe 3000 4
wperf report -i cpu.etl --symbol-path build\Release --percent-limit 0.5
wperf report -i cpu.etl --symbol-path build\Release --folded
```

## M2 已完成

- `record -- command` 目标进程记录。
- `record -p PID` attach 模式。
- `-F/--freq` 采样频率到 ETW profile interval 的转换。
- `OpenTraceW + ProcessTrace + CloseTrace` ETL replay。
- Classic system event 解码：
  - Process
  - Thread
  - Image load
  - PerfInfo SampledProfile
  - StackWalk
- sample IP 和 stack 事件解析。
- sample 缺失时按线程/CPU 回退关联。
- CPU flat report。
- trace quality：events、unknown、samples、stack events、samples_without_stack。
- Release 构建生成 PDB，支持本地符号化。

真实 ETL 验证结果：

- samples: 16552
- stack events: 16779
- samples_without_stack: 1042
- CPU burn 热点：`wperf_cpu_burn.exe!\`anonymous namespace'::Burn`，约 72%
- attach 模式：6133 samples，CPU burn 约 44%

## M3 已完成

- PE timestamp 读取。
- 模块身份校验：trace image timestamp 与磁盘 PE 不一致时拒绝 PDB，避免错符号。
- `\Device\HarddiskVolumeN` 到盘符路径转换。
- DbgHelp：
  - SymInitializeW
  - SymLoadModuleExW
  - SymFromAddrW
  - SymGetLineFromAddrW64
- module+offset 降级。
- flat report 过滤：
  - pid
  - tid
  - comm
  - dso
  - symbol
  - percent-limit
- folded stack。
- call tree。
- CSV、JSON。
- `buildid-list`。

## 当前限制

- Stack 关联已改为 raw QPC + TID + CPU；同一 key 多候选时使用 leaf IP 消歧，不再使用线程/CPU FIFO。StackWalkRef/Def 解析已加入 R0。
- inline frame 尚未展开。
- PDB cache 当前依赖 DbgHelp/`_NT_SYMBOL_PATH` 的标准缓存；尚无独立 `.symcache`。
- 内核模块符号依赖 symbol server 和网络。
- `record --elevate` 的真实 UAC 交互仍需人工验收。
