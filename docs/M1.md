# M1 基础能力

M1 的目标是建立可编译、可测试、可恢复的采集骨架，而不是实现 CPU stack report。

## 已实现

- C++20/CMake Windows 工程。
- `wperf --version`
- `wperf list`
- `wperf doctor`
- `wperf test`
- `wperf recover`
- `wperf record`
- ETW 系统 session 启动、停止和 profile interval 配置。
- profile source、PMC counter、活动 session 查询。
- 普通权限 controller + headless worker + session guard。
- 私有命名管道、nonce 握手和最小消息协议。
- correlation ID、JSONL 日志、原子状态文件。
- 未处理异常 minidump。
- worker IPC 和失败路径自动化测试。

## 验证

```powershell
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release --parallel
ctest --test-dir build -C Release --output-on-failure
pwsh -File .\scripts\m1_smoke.ps1
```

## 当前限制

- CPU stackwalk、symbolization 和 report 属于 M2。
- 当前开发会话不是管理员，因此真实 ETW 系统 session 的端到端测试仍需要管理员终端。
- 普通用户 + `--elevate` 的真实 UAC 交互需要人工确认。
- worker/guard 的状态和日志目录当前使用调用者 `%LOCALAPPDATA%`，要求 UAC 提权后仍是同一用户；独立管理员凭据场景后置。
